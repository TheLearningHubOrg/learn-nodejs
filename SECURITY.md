# Security Policy - learn-nodejs

## Supported Versions
We actively maintain and release security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within this project or documentation:
1. Do not open a public GitHub issue.
2. Email the maintainer directly at `manthan.ank@gmail.com` with a detailed description of the vulnerability, reproduction steps, and impact.
3. We will acknowledge receipt within 48 hours and work on a remediation patch.
